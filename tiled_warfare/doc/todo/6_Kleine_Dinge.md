# Kleine Dinge

Wie der Name sagt, handelt es sich hier um kleinere Sachen, die noch erledigt werden müssten.

## Aufgaben

1. **Scrollende Kamera.**

2. **Kamerafokus auf aktiven Charakter.**
   Da es passieren kann, dass bei einem Linksklick auf einen aktiven Charakter dieser von einer Textbox
   verdeckt wird, wenn sich dieser weit links oder weit rechts befindet, soll die Kamera auf einen
   Charakter hinscrollen, wenn dieser mit Links markiert und der Mousebutton losgelassen wurde.

3. **Tilemap zentrieren.**
   Im Moment wird im ScreenMain die Tilemap und verbundene Elemente linkszentriert angezeigt.
   Besser wäre jedoch, sie in die Mitte des Fensters zu schieben. Ist dies möglich?

4. **Bewegende Host Tokens.**
   Wenn der Host seine Tokens bewegt, sollen diese künftig nicht mehr teleportieren, sondern visuell
   von Position zu Position gleiten.

5. **Charakterbilder als Tokens.**
   Im Moment werden auf der Tilemap die Tokens als farbige Punkte angezeigt. Wäre es möglich diesen
   farbigen Punkten eventuell die, so vorhanden, hinterlegten Charakterbilder anzufügen?

6. **Nur ein Donald Trumpster.**
   Der Code für Donald Trumpster müsste leicht angepasst werden, dass er nur einmal existieren kann.
   Weitere Instanzen von ihm auf der Map, sollen, wie seine Zombies, amerikanische Vornamen, aber
   weiterhin Trumpster als Nachnamen haben.

7. "Back" Button im ScreenGameScreen soll als Gewinn für den Host gelten.
Im Moment ist es möglich straffrei über den Back Button vom ScreenGameScreen zurück in den ScreenRestaurant zu wechseln. Künftig soll bei einem Klick auf diesen Button zuerst ein Bestätigungsdialog erscheinen und dann, wenn er Spieler bestätigt, es als Sieg für den Host gewertet werden.
